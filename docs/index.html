How Data Updates Work
A GitHub Actions workflow runs every night at 06:00 UTC. It fetches historical price data from Fidelity factsheets server-side (bypassing CORS restrictions) and saves it as static JSON files in your repo under data/. The dashboard reads those files directly — no proxy, no API key, no extra accounts needed.
To add a new fund:
1. Add its ISIN to isins.txt in your repo (one per line)
2. Go to Actions → Fetch Prices → Run workflow to fetch immediately
3. Reload the dashboard — the fund appears automatically
See SETUP.md in the repo for full instructions
